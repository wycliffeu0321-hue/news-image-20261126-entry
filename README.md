# One Day in One Picture — 26 November 2026
A program that writes one image summing up the world's news of Thursday 26 November 2026: a Thanksgiving storm stops New York's parade, missiles over Kyiv, new US tariffs, North Korea's nuclear signal, strikes in Gaza and Kuwait, and more.
Run: python3 main.py (writes /output/entry.png; set MAKEFUN_OUTPUT_DIR to choose the folder). build_poster.py composes the poster from the panels in assets/.
